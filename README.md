# HB Relevé — Héritage Bois

Application de relevé de chantier (fenêtres, portes, volets), utilisable hors ligne sur téléphone.

- Adresse : https://agenceheritagebois-debug.github.io/hb-releve/
- Installation sur Android : ouvrir l'adresse dans Chrome → menu ⋮ → « Ajouter à l'écran d'accueil ».
- Les relevés, photos, clés IA et Dropbox restent sur le téléphone ; ce dépôt ne contient que le code de l'app.
